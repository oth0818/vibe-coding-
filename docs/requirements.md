# 요구사항 메모 (CLAUDE.md 초안용)

## 한 문장
월·화 점심에 1시간 공강이 있는 원형관 수강생이 공강 중에, 가고 싶은 곳을 지도에서 고르면 엘리베이터와 왕복 도보 시간을 빼고 몇 분 머물 수 있는지와 늦어도 언제 출발해야 하는지 알 수 있게 한다.

## 과제 하드 제약 (README)
- 브라우저에서 바로 실행되는 정적 웹. GitHub Pages로 열려야 함
- 백엔드 서버 없음. 저장은 localStorage만
- 핵심 기능 1개("이 공강에 이곳을 다녀올 수 있는가" 판정), 화면 3개 이하
- 금지: 회원가입/로그인, 결제, 실시간·다중 사용자, 추천 알고리즘, 자체 학습 모델, 서버 크롤링, 네이티브 앱
- 외부 API는 키가 필요 없는 공개 API만. 키를 저장소에 넣지 않음

## 파일 구조
- 앱은 저장소 맨 위 `index.html` 한 파일 (HTML, CSS, JS 모두 안에)
- `phase0/`, `prototype/`은 참고용 기록이라 읽지도 고치지도 않음
- `docs/log.md`는 내가 쓰는 기록이라 AI가 고치지 않음

## 화면 3개
1. 공강: 요일 선택, 공강 카드, 엘리베이터 붐빔/한산 토글, 머물 시간 입력, 지도(갈 수 있는 범위 원 + 저장한 곳 점), 가게 검색, 고른 곳 판정 결과, 저장한 곳 목록
2. 저장한 곳: 장소별 머물 시간, 직접 잰 편도 도보 시간, 영업시간, 브레이크타임 수정과 삭제
3. 시간표: 내 시간표를 주간 표로 보기

## 계산 규칙 (숫자는 바꾸지 말 것)
- 공강: 같은 요일 연속 수업 사이 간격이 20분 이상이면 공강
- 지금 모드: 오늘 공강 중이면 현재 시각부터 계산
- 층 이동 (출발 층 → 1층, 1층 → 도착 층)
  - 1층: 0분
  - 2층: 계단 1분
  - 3층 이상: 엘리베이터. 붐빔 5분, 한산 1분 (화면 토글, 기본값 붐빔)
- 도보 시간(분) = 올림(거리m ÷ 75) + 1 (건물 출입 1분)
  - 거리는 길 찾기 결과를 쓰고, 실패하면 직선거리 × 1.3
  - 장소에 직접 잰 편도 도보 시간이 있으면 그 값을 씀
- 가는 시간 = 출발 강의실 층 이동 + 도보(출발 건물 → 장소)
- 돌아오는 시간 = 도보(장소 → 다음 수업 건물) + 다음 강의실 층 이동
- 머물 수 있는 시간 = 남은 공강 − 가는 시간 − 돌아오는 시간 − 여유 2분
- 가능 여부: 머물 수 있는 시간 ≥ 장소의 머물 시간이면 "가능", 아니면 "N분 부족"
- 늦어도 출발 시각 = 다음 수업 시작 − 돌아오는 시간 − 여유 2분
- 영업시간: 도착 시각부터 머물 시간 동안 영업시간 밖이거나 브레이크타임과 겹치면 "시간은 되지만 문 닫았을 수 있음"
- 갈 수 있는 범위 원 반지름(m) = ((남은 공강 − 두 번의 층 이동 − 머물 시간 − 여유 2분 − 출입 2분) ÷ 2) × 75 ÷ 1.3. 직선 기준 대략적인 범위라고 화면에 표시

## 표시 원칙
- "추천"이라는 말과 "가장 좋은 곳" 1등 뽑기를 쓰지 않음. "가능 / N분 부족"과 머물 수 있는 시간만 보여주고, 머물 수 있는 시간이 긴 순으로 정렬
- 라이트 모드와 다크 모드 둘 다 글자가 배경과 충분히 구분돼야 함

## 외부 서비스 (모두 키 없음)
- 지도: OpenStreetMap 타일 + Leaflet (출처 표시 필수)
- 가게 검색: Nominatim. 검색 버튼을 눌렀을 때만 요청 (자동완성 금지). 캠퍼스 주변 범위로 제한
- 길 찾기: routing.openstreetmap.de 도보 경로
- 어느 하나가 실패해도 판정은 계속 동작해야 함 (지도 숨김, 직선 추정으로 대체)

## 작업 방식 (Phase 0에서 배운 것)
- 한 번에 기능 하나만. 코드를 쓰기 전에 계획을 먼저 말하고 내 확인을 받음
- 요청하지 않은 기능(다크모드, 즐겨찾기 등)을 추가하지 않음. 필요해 보이면 제안만 함
- 브라우저 화면 확인은 내가 함. AI는 직접 확인하지 못한 것은 "확인 못 함"이라고 분명히 말함
- 큰 파일을 문자열 잘라 붙이기로 고치지 않음 (Phase 0에서 파일이 깨졌음)
- 커밋은 내가 요청할 때만, 기능 하나당 한 번
